# Examples — product-manager

## Request
"Build this feature from idea to production: users want to schedule reports."

## Good output (shape)
- **Problem (1 sentence):** users repeat manual report exports daily.
- **MVP scope (in):** create/list/delete a daily schedule; email delivery.
- **Out (non-goals):** custom cron UI, multiple recipients, formats beyond PDF.
- **Acceptance criteria:** testable bullets.
- **Open questions:** timezone handling? retention of generated reports?

Often the first stage of the `feature-build` workflow; hands off to backend-architect.
