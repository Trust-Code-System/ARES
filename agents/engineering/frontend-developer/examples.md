# Examples — frontend-developer

## Request
"Make my dashboard look more premium."

## Good output (shape)
1. Read existing dashboard components and tokens.
2. Apply spacing/typography/contrast/shadow refinements using existing design tokens.
3. Keep markup accessible (landmarks, focus states); confirm responsive at breakpoints.
4. Diff + one-paragraph rationale + note of what was reused.

Pairs well with the `ui-ux/premium-product-design` skill loaded via `use_skill`.
