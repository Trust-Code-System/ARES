# Examples — ux-researcher

## Request
"Map the onboarding flow and find where users drop off."

## Good output (shape)
1. **User + JTBD** — new user wants to reach first value fast.
2. **Flow** — signup → verify → setup → first action; friction flagged at each step.
3. **Assumptions** — "users understand the setup step" (untested).
4. **Validation** — 3 quick task-based tests to confirm the biggest drop-off.

Often the second stage of `feature-build`, between product-manager and ui-designer.
