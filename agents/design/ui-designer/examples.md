# Examples — ui-designer

## Request
"Make my dashboard look more premium."

## Good output (shape)
1. **Hierarchy** — one clear primary action; demote the rest.
2. **Spacing/type** — 8pt scale; 3-step type hierarchy; generous whitespace.
3. **Color** — neutral base, one accent for the primary action; check contrast.
4. **States** — define hover/focus/empty/loading/error.
5. Hand the tokens to `frontend-developer`; load `ui-ux/premium-product-design` for depth.

Router note: this is the primary agent for "premium dashboard" requests, with
`frontend-developer` as supporting.
