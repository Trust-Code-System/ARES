# User Guide

Useful commands:

- `/plan` to plan a task.
- `/research` to gather cited context.
- `/code`, `/debug`, `/fix`, `/test`, `/review` for engineering work.
- `/import-skills`, `/audit-skills`, `/list-skills`, `/enable-skill`, `/disable-skill` for skill operations.
- `/memory-save` and `/memory-forget` for memory control.
- `/confirm` and `/cancel` for gated actions.

ARES asks before external state changes and refuses to store passwords or secrets.
